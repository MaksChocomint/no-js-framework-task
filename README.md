# no-js-framework-task

Список пользователей с [dummyjson.com/users](https://dummyjson.com/users), выведенный на страницу с помощью htmx, без собственного JavaScript.

**Приложение:** https://makschocomint.github.io/no-js-framework-task/

## Как работает

- При открытии страницы `#users` с `hx-trigger="load"` запрашивает первые 12 пользователей. Через `select` берутся только нужные поля.
- **Бесконечная прокрутка.** Последний элемент списка содержит `hx-trigger="revealed"` и `hx-swap="outerHTML"`. Когда он появляется на экране, он подменяет себя следующей порцией. Следующий `skip` считается прямо в шаблоне: `{{ skip + limit }}`.
- **Поиск.** Поле ввода отправляет запрос на `/users/search` с `hx-trigger="input changed delay:400ms"`, чтобы не слать запрос на каждую букву.
- **Профиль.** Клик по карточке запрашивает `/users/{id}`, и профиль открывается в отдельном окне. Закрыть его можно крестиком, кликом по фону или клавишей Esc.

## Инструменты и почему

- **htmx 2.** Запросы и вставка результата описаны атрибутами в разметке. В `htmx-config` выставлено `selfRequestsOnly: false`, потому что по умолчанию htmx 2 запрещает запросы на чужой домен (CORS у dummyjson открыт).
- **Расширение client-side-templates и шаблонизатор Nunjucks.** htmx ждёт от сервера HTML, а dummyjson отдаёт JSON, поэтому JSON превращается в HTML прямо в браузере. Nunjucks умеет считать в шаблоне (`skip + limit`, условие `skip + limit < total`) и поддерживает ветку `for … else` для «никого не нашлось». Данные при этом экранируются.
- **_hyperscript.** Закрытие окна профиля записано одной строкой в атрибуте `_`, без JavaScript.
- Страница статическая, сервер не нужен, она размещена на GitHub Pages.
